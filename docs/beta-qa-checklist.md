# Beta QA Checklist

β版移行前に確認する運用目線のチェックリストです。

## 認証

- 新規登録後に `/auth` で止まらず、家族ルーム作成へ進める
- 招待コード参加後に正しい `/rooms/[familyId]` へ入る
- ログイン済みで `/home` に入ると自分の家族ルームへ転送される

## メッセージ

- メッセージ画面を開くと既読人数が増える
- テンプレート投稿が短時間で送れる
- メッセージ0件でもデモデータに戻らず空状態が出る

## 報連相

- ご飯連絡で `食べる / 取り置き / いらない` が返せる
- 欠食届、外泊届、お迎え相談を短い入力で出せる
- 完了導線が迷わない

## 地図 / 場所

- 手動共有と自動共有のモード差が分かる
- 現在地更新後に場所一覧が更新される
- 登録地点から外部地図が開ける

## 日記 / 公開

- 日記投稿時に公開範囲が選べる
- 公開範囲表示が投稿一覧で分かる

## タスク / 通知

- タスク作成と完了ができる
- 家族設定でタスクをOFFにするとホームに出なくなる
- 通知レベル設定が保存される

## 画面密度

- ホームの最上部だけで未読 / 報連相 / タスクの状況が分かる
- スマホで各主要画面が読みやすい
- 使わない機能がメニューに出すぎていない
